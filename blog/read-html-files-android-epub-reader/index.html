You save a long article from your browser. You export a page of documentation. Someone sends you a chapter that was pulled out of an ebook. All of it is HTML, and all of it ends up in your Downloads folder — where it stays, because tapping it opens a browser tab with no font control, no dark themes, no bookmarks, and no place to leave a note.

Shiori treats an HTML file as a book. Import it once and it sits on your bookshelf right next to your EPUBs, with the exact same reading tools attached: continuous scroll, custom typography, text-to-speech read-aloud, on-device translation, and bookmarks.

Shiori reads the semantic markup, not a flat picture of the page. Headings stay headings, lists stay lists, tables stay tables, and text reflows gracefully to your screen width, your custom font, and your chosen margins.

Two Key Details to Know Before You Start

  • The book title comes from the file's <title> tag: A page saved with a generic name like article(3).html will still appear on your bookshelf under its real article title.
  • The character encoding comes from the file's own declaration: A page that specifies Shift_JIS or windows-1251 is read in its native encoding, not guessed at as UTF-8. This prevents garbled character glitches.

2 จุดเด่นสำคัญที่ควรรู้ก่อนเริ่มใช้งาน

  • ชื่อหนังสือถูกดึงจากแท็ก <title> อัตโนมัติ: แม้ไฟล์จะตั้งชื่อว่า article(3).html แต่บนชั้นหนังสือจะแสดงชื่อหัวข้อบทความจริงอย่างถูกต้อง
  • ตรวจจับการเข้ารหัสอักขระ (Encoding) จากไฟล์โดยตรง: ไฟล์ภาษาญี่ปุ่นเก่าแบบ Shift_JIS หรือภาษารัสเซียแบบ windows-1251 จะถูกอ่านตามรหัสที่ระบุ ไม่เกิดปัญหาตัวอักษรต่างดาว
โหมดแสดงผลตารางพฤติกรรมการแสดงผลกรณีการใช้งานที่แนะนำ
Wrapped (ตัดบรรทัด - ค่าเริ่มต้น)ข้อความในช่องจะตัดขึ้นบรรทัดใหม่ แสดงครบทุกคอลัมน์บทความยาว ตารางคู่มือ API ที่มีคำอธิบายยาวๆ
Single-Line Scroll (บรรทัดเดียวเลื่อนข้าง)ข้อความอยู่บรรทัดเดียว ตารางกะทัดรัดและใช้นิ้วเลื่อนแนวนอนตารางสเปก ตัวเลข การเปรียบเทียบข้อมูลแบบกระชับ
ปลอดภัย ไม่กระทบไฟล์ต้นฉบับ:
การนำเข้าจะทำการคัดลอกไฟล์เข้าสู่คลังของแอป Shiori โดยไฟล์เดิมในโฟลเดอร์ Downloads จะยังคงอยู่เหมือนเดิมทุกประการ

ブラウザで保存したWeb記事、出力したAPIドキュメント、配布されたHTMLファイル。これらはスマホのブラウザで開くとフォント調整やダークテーマ、しおり機能が使えず、読書には不向きでした。

ShioriはHTMLファイルを1冊の「書籍」として扱います。 一度取り込めば本棚にEPUBと並んで配置され、連続スクロール、フォント変更、音声読み上げ（TTS）、翻訳、しおり・メモなど全ての読書ツールがそのまま利用できます。

ページの画像をただ表示するのではなく、HTMLのタグ構造を解析して文字をリフローするため、スマホの画面幅に合わせて美しく再レイアウトされます。

知っておくべき2つのポイント

  • 書籍名は <title> タグから自動取得： ファイル名が page(1).html のような名前でも、本棚には正しい記事タイトルで並びます。
  • 宣言された文字コードを正確に読み込み： 古い日本のWebサイトの Shift_JIS 宣言も正確に解釈し、文字化けを起こさず表示します。

1Add Files in Batches via the File Picker

On your bookshelf, tap the floating + button in the bottom-right corner to open the system file picker.

To bring in multiple articles at once, long-press the first file to enter selection mode, then tap the rest. Tap Select to import the entire batch.

Shiori reports the outcome immediately: it confirms the number of imported books and names any unsupported file.

1เลือกและนำเข้าไฟล์ HTML ทีละหลายไฟล์

ในหน้าชั้นหนังสือ ให้แตะปุ่ม + ที่มุมล่างขวาเพื่อเปิดหน้าต่างเลือกไฟล์ของระบบ

หากต้องการนำเข้าหลายไฟล์พร้อมกัน ให้แตะค้างที่ไฟล์แรกเพื่อเปิดโหมดเลือกหลายรายการ จากนั้นแตะเลือกไฟล์อื่นๆ แล้วกด Select เพื่อนำเข้าทั้งชุด

Shiori จะแจ้งผลลัพธ์ทันทีว่าสามารถนำเข้าได้กี่เล่ม และระบุชื่อไฟล์ที่ไม่สามารถเปิดได้ (ถ้ามี)

1ファイルピッカーからまとめて取り込む

本棚画面の右下にある + ボタンをタップしてファイル選択画面を開きます。

最初のファイルを長押しして複数選択モードに入り、残りのファイルをタップして Select を押すと、一括で取り込めます。

取り込み結果が通知され、追加された冊数や受け入れられなかったファイル名が明示されます。

1通过文件选择器批量导入 HTML

在书架界面点击右下角的 + 悬浮按钮，打开系统文件选择器。

长按第一个文件进入多选模式，依次勾选其他 HTML 文档，点击 Select 即可一键批量导入。

Shiori 会即时反馈导入结果，明确提示成功导入的图书数量及无法识别的文件名。

1Adicione Arquivos em Lote pelo Seletor

Na estante, toque no botão flutuante + no canto inferior direito para abrir o seletor de arquivos.

Pressione e segure o primeiro arquivo para ativar a seleção múltipla, marque os demais e toque em Select.

O Shiori informa o resultado do lote, confirmando quantos livros foram importados com sucesso.

1Añade Archivos por Lotes desde el Selector

En la estantería, pulsa el botón flotante + en la esquina inferior derecha para abrir el selector.

Mantén pulsado el primer archivo para activar la selección múltiple, toca los demás y pulsa Select para importar.

Shiori informa de inmediato cuántos libros se han añadido y avisa si algún archivo no es compatible.

2HTML Books on Your Bookshelf

Each imported HTML document appears on the bookshelf titled from its <title> tag and clearly badged HTML.

Expand a book's detail card to see its source filename. From here, you can track progress, use full-text search, add bookmarks, and trigger TTS read-aloud just like an EPUB.

2หนังสือ HTML พร้อมป้ายกำกับบนชั้นหนังสือ

กดขยายดูรายละเอียดเพื่อดูชื่อไฟล์เดิม สามารถติดตามความคืบหน้าการอ่าน ค้นหาข้อความ คั่นหน้า และเปิดเสียงอ่าน TTS ได้เหมือนหนังสือ EPUB

2本棚にHTMLバッジ付きでスマートに並ぶ

詳細カードで元のファイル名を確認でき、読書進捗の管理、全文検索、しおり、TTS朗読などがそのまま利用可能です。

展开书籍详情可查看原始文件名。支持阅读进度记录、全文检索、添加书签与卡拉OK式 TTS 语音朗读。

3Wide Tables: The Word-Wrap Toggle Button

Wide tables are notoriously hard to read on phone screens. Every table in Shiori gets a dedicated round button at its top-left corner to switch how it handles width.

Wrapped Mode: Breaks cell text into multiple lines so all columns stay visible together. Single-Line Mode: Keeps rows compact and allows smooth horizontal scrolling under your finger.

3จัดการตารางขนาดกว้างด้วยปุ่มสลับการตัดคำ (Wrap Toggle)

ตารางข้อมูลหลายคอลัมน์มักอ่านยากบนจอมือถือ Shiori จึงใส่ปุ่มกลมเล็กๆ ไว้ที่มุมบนซ้ายของทุกตารางเพื่อให้คุณเลือกวิธีแสดงผลได้ตามต้องการ

โหมด Wrapped: ตัดข้อความในช่องหลายบรรทัดเพื่อแสดงทุกคอลัมน์บนจอ โหมด Single-Line: ตรึงข้อความบรรทัดเดียว แถวกะทัดรัดและใช้นิ้วเลื่อนแนวนอนได้อย่างอิสระ

3幅広テーブルを快適化：折り返し切替ボタン

列数の多い比較表をスマホで快適に読めるよう、各テーブルの左上に丸い切り替えボタンが配置されています。

折り返しモード： セル内を自動改行し全列を画面内に表示。 1行スクロールモード： セルを1行に固定し指で左右に横スクロールして軽快に閲覧。

3宽表格应对方案：折行与滚动一键切换

针对多列对比表格在手机端难以排版的痛点，Shiori 在每个表格左上角均提供了一个圆形的排版切换按键。

折行模式： 单元格文字自动换行，所有列同屏呈现。 单行滚动模式： 单元格保持单行紧凑，支持手指左右横向滑动浏览。

3Tabelas Largas: Botão de Quebra de Linha

Tabelas com muitas colunas recebem um botão circular no canto superior esquerdo para alternar a exibição.

Modo Quebrado: Texto quebra em várias linhas mantendo tudo visível. Modo Linha Única: Células compactas em uma linha com rolagem horizontal.

3Tablas Anchas: Botón de Ajuste de Línea

Las tablas con muchas columnas incluyen un botón circular en la esquina superior izquierda para cambiar de modo.

Preguntas Frecuentes y Solución de Problemas (FAQ)

What should I do if a copied file doesn't appear in the file picker?
Files transferred over USB are sometimes not immediately indexed by Android MediaStore. Open the folder once using your device's built-in file manager, or restart the device, and the file will appear immediately.
ทำอย่างไรถ้าไฟล์ HTML ที่เพิ่งก๊อปลงเครื่องไม่แสดงในหน้าต่างเลือกไฟล์?
ไฟล์ที่ถ่ายโอนผ่านสาย USB บางครั้งระบบ Android อาจยังไม่ได้ทำดัชนี (Index) แนะนำให้เปิดแอปจัดการไฟล์ (File Manager) ของเครื่องเข้าไปดูโฟลเดอร์นั้นหนึ่งครั้ง หรือรีสตาร์ตเครื่อง ไฟล์จะปรากฏให้เลือกทันที
USB経由でコピーしたファイルがピッカーに表示されない場合は？
Androidのメディアインデックスが未更新の場合があります。端末標準のファイルマネージャーで対象フォルダを一度開くか、端末を再起動するとピッカーに表示されます。
通过 USB 导入的 HTML 文件未出现在选择器中怎么办？
部分通过 USB 传输的文件可能未被 Android 系统及时建立索引。使用手机自带的文件管理器打开该文件夹一次，或重启手机即可正常显示。
O que fazer se um arquivo transferido por USB não aparecer no seletor?
Arquivos copiados via USB podem não ser indexados na hora pelo Android. Abra a pasta pelo gerenciador de arquivos do celular ou reinicie o aparelho para que apareçam.
¿Qué hacer si un archivo copiado por USB no aparece en el selector?
Los archivos copiados por USB a veces tardan en ser indexados por Android. Abre la carpeta con el explorador de archivos del móvil o reinicia el dispositivo para verlo.
Can I hide table gridlines to make dense documentation look cleaner?
Yes. In Reading settings, simply toggle off Show table borders to remove heavy gridlines across the entire book for a minimalist reading experience.
สามารถซ่อนเส้นขอบตารางเพื่อให้หน้าเอกสารดูสะอาดตาขึ้นได้หรือไม่?
ทำได้ครับ ในเมนู Reading settings (การตั้งค่าการอ่าน) จะมีตัวเลือก Show table borders (แสดงเส้นขอบตาราง) คุณสามารถปิดตัวเลือกนี้เพื่อซ่อนเส้นขอบตารางทั่วทั้งเล่มได้ทันที
テーブルの枠線を非表示にしてシンプルに読めますか？
はい。Reading settings（読書設定）内の Show table borders（表の枠線を表示）をオフにすると、書籍全体の表の枠線を消してすっきりと読めます。
可以隐藏表格边框以获得更简洁的排版吗？
可以。在 Reading settings（阅读设置）中，关闭 Show table borders（显示表格边框）开关，即可隐藏全书所有表格的网格边框线。
É possível ocultar as bordas das tabelas para uma leitura mais limpa?
Sim. Em Reading settings, desative a opção Show table borders para remover as grades de todas as tabelas do documento.
¿Se pueden ocultar los bordes de las tablas para una lectura más limpia?
Sí. En Reading settings, desactiva la casilla Show table borders para quitar las líneas de cuadrícula de todas las tablas del libro.
Should I save pages as "HTML Only" or "Webpage, Complete"?
We recommend saving as "Webpage, Complete" if you want embedded images and illustrations to be saved in an accompanying folder for offline reading.
ควรบันทึกหน้าเว็บแบบ "HTML Only" หรือ "Webpage, Complete"?
แนะนำให้เลือกบันทึกแบบ "Webpage, Complete" หากคุณต้องการให้รูปภาพและภาพประกอบในบทความถูกบันทึกมาด้วยเพื่อการอ่านแบบออฟไลน์ที่สมบูรณ์แบบ
保存時は「HTMLのみ」と「完全なWebページ」のどちらが良いですか？
記事内の画像やイラストも一緒にオフラインで閲覧したい場合は、「完全なWebページ（Webpage, Complete）」で保存することをおすすめします。
保存网页时应选择“仅 HTML”还是“完整网页”？
如果文章中包含重要的图表与插图，建议选择“完整网页（Webpage, Complete）”保存，以便将配图一并保存在同名资源文件夹中离线浏览。
Devo salvar como "Apenas HTML" ou "Página Completa"?
Recomendamos salvar como "Página da Web Completa" para que as imagens do artigo sejam salvas junto e exibidas offline.
¿Es mejor guardar como "Solo HTML" o "Página web completa"?
Recomendamos guardar como "Página web completa" si el artículo contiene imágenes o esquemas que quieras ver sin conexión.
