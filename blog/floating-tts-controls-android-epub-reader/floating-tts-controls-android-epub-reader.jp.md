# 他のアプリを使いながら音声朗読を継続：ShioriのフローティングTTSコントロール機能

電子書籍の章を音声読み上げ（TTS）で聴きながら読書を進めている最中に、メッセージ通知が届くことがあります。返信のためにメッセージアプリを開くと、朗読音声はバックグラウンドで流れ続けるものの、一時停止したり、一文巻き戻したり、今どの行を読んでいるのかを確認するためには、作業を中断してリーダーアプリ画面へ戻らなければなりませんでした。

**Shioriの「フローティングコントロール（Floating Controls）」がこの課題を解決します。** この機能を有効にすると、利用中のあらゆるアプリ画面の上に小型の操作カードが常に最前面表示されます。現在読み上げられている文と単語がリアルタイムにカラオケ風ハイライトされ、フル機能の再生ボタンが備わっているため、他アプリを開いたまま指一本で一時停止、スキップ、書籍の該当位置へのジャンプが可能です。

本ガイドでは、本機能の有効化、必要な権限の許可、サイズ・配色・透明度の微調整、および他アプリ操作時の実際の活用方法を詳しく解説します。掲載しているスクリーンショットはすべて、Shiori 2.3.6 を搭載した実機Androidスマートフォンで撮影されたものです。

## フローティングカードが提供する主な機能

フローティングカードは単なる再生・停止ウィジェットではありません。デフォルトで以下の多彩な機能を凝縮しています：

* **カラオケティッカー（Karaoke line）：** 読み上げ中の文章を1行でスクロール表示。発声中の単語を別色でハイライトするため、本を開かずに内容を目で追えます。
* **位置へジャンプ（Go to position）：** 左端のアイコンをタップすると、Shioriリーダーが即座に開き、朗読中の箇所へ画面が移動します。
* **単語置換ルールを追加（Add text replacement）：** 耳にしたばかりの箇所に対してその場で置換ダイアログを開き、誤読する固有名詞の読み方を素早く修正できます。
* **前へ / 再生・一時停止 / 次へ（Previous / Play-Pause / Next）：** 親指で押しやすい大型トランスポートボタン。
* **閉じるボタン（×）：** カードを閉じ、音声朗読を終了します。

## 必要な準備

* Android端末にインストールされたShioriアプリ（バージョン2.3.6で検証）
* ライブラリ内の任意の電子書籍（本解説では『*ドリアン・グレイの肖像*』を使用）
* 動作するAndroid TTSエンジン（OS標準の音声エンジンで問題ありません）
* 他アプリの上に重ねて表示する権限（機能オン時にShioriから許可を求められます）

## ステップ 1: フローティングコントロールを有効にする

1. 本棚画面上部のツールバーにある設定歯車アイコン（**Settings**）をタップします。
2. **TTS Listening** を選択します。
3. **Floating Controls**（他アプリ上に再生コントロールを表示）の行を見つけ、右側のスイッチをオンにします。

この行には2つの重要要素があります。右側のトグルスイッチでオン/オフを切り替え、その隣の小さな歯車アイコンで詳細な外観設定ページを開くことができます。この歯車はステップ3で使用します。

![ShioriのTTS設定画面。Floating Controlsスイッチがオンになっており、外観ページを開く歯車が表示されている](01-floating-controls-switch-in-tts-settings.jpg)

## ステップ 2: 他アプリへの重ねて表示権限を許可する

スイッチを入れた瞬間に、Shioriから以下の許可ダイアログが表示されます：

> **Floating Controls** — Allow Shiori to show TTS controls over other apps while reading in background?

**Allow** をタップしてください。これはAndroidシステムのオーバーレイ権限です。許可しないとOSが他アプリの上に描画することを制限するため、カードが表示されません。システム設定画面に誘導された場合は、権限を許可してアプリに戻ってください。

**Not Now** を選択した場合でも通常の音声読み上げは動作しますが、フローティングカードは画面上に出現しません。

![他アプリへの重ねて表示許可を求めるダイアログ。Not NowとAllowの選択肢が表示されている](02-allow-controls-over-other-apps.jpg)

## ステップ 3: 設定画面でカードの形状と動作を調整する

Floating Controlsスイッチ横の歯車アイコンをタップします。**Floating control** 設定ページが開き、上部にリアルタイムプレビュー（**Preview**）が表示されます。スライダーやスイッチを操作すると即座にカードが再描画されるため、他アプリへ移動する前に仕上がりを確認できます。

このページ内の主な設定スイッチ：

* **Karaoke ticker on floating controls：** 段落全体ではなく1行スクロールで文字を表示。読み上げ単語は左寄せ（RTL言語では右寄せ）になります。テキストを目で追いたい場合はオン、ボタンのみで十分な場合はオフにします。
* **Keep the word in the middle：** 発声中の単語を常に中央に固定します。単語の位置が常に一定になるため、読書追従が非常に快適になります。
* **Hide the control buttons：** 操作ボタンを隠して純粋なテキストバーに変え、左端のジャンプボタンのみを残します。
* **Full-width floating card：** 画面の横幅いっぱいにカードを広げます。この状態では上下の垂直方向のみに移動可能となります。
* **Snap the floating card to an edge：** **Free** は置いた位置にそのまま静止、**Top** または **Bottom** はドラッグ後に自動で画面上端または下端へスナップ吸着します。

![ShioriのFloating control設定画面。上部にプレビューカード、各種スイッチとスナップ設定が並ぶ](03-floating-control-options-and-preview.jpg)

## ステップ 4: サイズ・余白・配色を設定する

同じページを少し下へスクロールすると、外観調整スライダーが並んでいます：

| 設定項目 | デフォルト | 変更される内容 |
| --- | --- | --- |
| Floating control size | ×1.0 | ボタンを含むカード全体のスケール倍率 |
| Margin | 8dp | カードと画面端との間の外側マージン |
| Padding | 8dp | カード内部の余白スペース |
| Font size | 13sp | カラオケ行のテキスト文字サイズ |
| Background opacity | 90% | 背後のアプリがどの程度透けるかの不透明度 |

スライダーの下には3つのカラーパレットがあります：通常テキスト用の **Text colour**、現在発声中の単語用の **Aloud text colour**、そしてカード自体の **Background colour** です。カードは様々な他アプリの上に表示されるため、コントラストが非常に重要です。不透明度を高めにした濃い背景色に明るい文字色を選ぶと、どんな画面でも常に読みやすくなります。

目立たなくしたい場合は、カードサイズを縮小するよりも **Background opacity**（背景不透明度）を下げるのがおすすめです。半透明で見やすいカードのほうが、目を凝らさなければ見えない極小カードよりも快適です。

![設定画面下部。サイズ、余白、文字サイズ、不透明度スライダーと3色のカラーパレットが表示されている](04-floating-card-size-and-colours.jpg)

## ステップ 5: リーダーで音声朗読を開始する

音声が再生されるまでフローティングカードは出現しません。ライブラリから本を開き、リーダー画面下部のコントロールバーにある再生ボタンをタップします。

Shioriが最前面にある間は、リーダーならではの充実したUIを楽しめます。読み上げ中の段落がハイライトされ、現在の単語が強調され、下部バーに章内の進行状況が表示されます。

![Shioriで開かれたドリアン・グレイの肖像。音声朗読が実行中で、段落と単語がハイライトされている](05-start-listening-in-the-reader.jpg)

## ステップ 6: 他のアプリへ移動 — カードが画面上に追従

ここでホーム画面に戻るか、他のアプリ（ブラウザやSNSなど）に切り替えます。フローティングカードが画面上に浮き上がり、単語単位で朗読を追跡し続けます。

カード本体を指でドラッグすれば、好きな位置へ移動できます。スナップを **Free** にしている場合は離した場所にとどまり、**Top** や **Bottom** にしている場合は画面端へスライドします。位置を見失った場合は、**カードをダブルタップ** すると画面中央へ即座に復帰します。

![Webブラウザ画面の上に重なって表示されているShioriのフローティングカード](06-floating-card-over-another-app.jpg)

## ステップ 7: 全幅スリムなミニマルレイアウト

標準のカードが少し大きく感じる場合は、**Hide the control buttons** と **Full-width floating card** を同時にオンにします。すると、画面横幅いっぱいに広がるスリムな情報バーに変化します。ジャンプボタン、小さな一時停止ボタン、カラオケ行、閉じるボタンのみの極めてすっきりした構成です。

このレイアウトは垂直方向のみに移動できます。ステータスバーの直下や画面最下部に固定しておけば、メインアプリの操作を一切妨げません。

![ミニマル全幅モードのフローティングコントロール。ブラウザの上部に細い帯状で表示されている](07-minimal-full-width-card.jpg)

## ステップ 8: アプリに戻らずその場で読み間違いを修正

カード上の2つ目のアイコンをタップすると、利用中のアプリの上に直接 **Add Text Replacement**（テキスト置換ダイアログ）が開きます。

書籍の原文を **Find (from)** に、正しい読み方を **Replace with (to)** に入力し、画面上の文字を変えずに音声のみ変更する **TTS** モードを選択して保存します。他アプリでの作業や読書の流れを止めずに、わずか数秒で誤読を解消できます。

![フローティングカードから開かれたAdd Text Replacementダイアログ](08-add-text-replacement-from-the-card.jpg)

## トラブルシューティング（よくある質問）

**カードが全く表示されない**  
オーバーレイ権限が拒否された可能性があります。**Floating Controls** のスイッチをオフにして再度オンにしてダイアログを再表示させるか、Android本体の設定からShioriの「他のアプリの上に重ねて表示」を許可してください。

**カードはあるが文字が表示されない**  
「**Karaoke ticker on floating controls**」がオフになっているため、ボタン専用モードになっています。設定から再度オンにしてください。

**明るい背景のアプリの上で文字が見づらい**  
**Background opacity**（背景不透明度）を90%〜100%に上げ、濃い背景色と明るいテキスト色の組み合わせを選択してください。

**カードを端に移動しすぎて操作しにくい**  
カードを素早く **ダブルタップ** すると、即座に画面中央へ戻ります。またはスナップ設定を **Top** や **Bottom** に固定してください。

**×ボタンを押したら朗読が停止した**  
これは正常な動作です。×ボタンはカードの破棄と同時に音声朗読を終了します。カードを非表示にして音声だけ流し続けたい場合は、設定で **Floating Controls** のスイッチのみをオフにしてください。

## 活用のプロTips

* **右横書き（RTL）書籍への自動適応：** アラビア語などの書籍では、ティッカーの進行方向が自動で右揃えになり、自然な読書感を維持します。
* **ワンタップしおり代わり：** 他アプリの作業中に耳で進んだ位置へ、カード左端のジャンプボタンを1回タップするだけで書籍画面を同期復帰できます。
* **設定前にリアルタイムプレビューを活用：** 設定画面上部のプレビューを活用して、あらかじめ最適なフォントサイズと配色を調整しておきましょう。

## まとめ

Shioriのフローティングコントロールは、音声朗読中に最も必要な要素――現在の一文と再生ボタン――をアプリの外へと連れ出してくれます。スイッチをオンにして権限を1度許可するだけで、スマホで別の作業をしている間も、大好きな本が常にあなたのそばに寄り添います。
