Komga, OPDS, or Komga API? Pick the right one first

When you add a server, Shiori offers several quick-fill options, and three of them mention Komga. They are not equivalent:

OptionProtocolFeatures
KomgaOPDS v1Browsing & downloading only
Komga v2OPDS v2Browsing & downloading only
Komga API ⭐Native REST APICovers, full book details & reading-progress sync

OPDS is a generic catalog standard, so it works with almost any server — Calibre, Calibre-Web, Standard Ebooks, Project Gutenberg. That generality is also its limit: it carries just enough information to list and download a file.

Komga's own API knows about series, metadata and read progress, so Shiori can show you a real library instead of a file list, and tell Komga where you stopped reading.

Use "Komga API" unless you have a specific reason not to.

What you need

  • Komga running and reachable on your network
  • Your Komga username and password (or an API key, if you prefer)
  • Your server's LAN address — not localhost
  • Shiori installed on your Android device
Why not localhost?
localhost means this device. Typed into your phone, it points at the phone, not at your server. You need the address your server has on your network — something like 192.168.1.33.

ตัวเลือกโปรโตคอลความสามารถ

API ของ Komga โดยเฉพาะนั้นเข้าใจเรื่องซีรีส์ ข้อมูลเมทาดาตา และความคืบหน้าการอ่าน Shiori จึงสามารถแสดงคลังหนังสือจริงๆ แทนที่จะเป็นแค่รายการไฟล์ และยังแจ้ง Komga ได้ว่าคุณอ่านค้างไว้ที่ตรงไหน

  • ที่อยู่ LAN ของเซิร์ฟเวอร์ — ไม่ใช่ localhost
  • แอป Shiori ที่ติดตั้งอยู่บนอุปกรณ์ Android ของคุณ
ทำไมถึงไม่ใช้ localhost?
localhost หมายถึง อุปกรณ์เครื่องนี้ หากพิมพ์ลงในโทรศัพท์ จะเป็นการชี้กลับมาที่ตัวโทรศัพท์เอง ไม่ใช่เซิร์ฟเวอร์ของคุณ คุณต้องใช้ที่อยู่ IP ที่เซิร์ฟเวอร์ได้รับในเครือข่ายของคุณ เช่น 192.168.1.33

Komga、OPDS、それとも Komga API？ まずは正しい接続方法を選ぼう

サーバーを追加する際、Shioriはいくつかの自動入力オプション（クイックフィル）を提供しており、そのうち3つにKomgaの名前が含まれています。これらは機能が異なります：

選択肢通信プロトコル対応機能
KomgaOPDS v1閲覧とダウンロードのみ
Komga v2OPDS v2閲覧とダウンロードのみ
Komga API ⭐ネイティブ REST API表紙、詳細な本情報、読書進捗の同期

OPDSは汎用的なカタログ規格であるため、Calibre、Calibre-Web、Standard Ebooks、Project Gutenbergなど、ほぼすべてのサーバーで動作します。しかし、その汎用性の高さゆえに限界もあり、ファイルをリスト表示してダウンロードするための最小限の情報しか保持できません。

一方、Komga独自のAPIはシリーズ、メタデータ、読書進捗を識別できるため、Shioriはファイル一覧ではなく本物のライブラリを表示でき、どこまで読んだかをKomgaに伝えることができます。

特別な理由がない限り、「Komga API」を使用してください。

必要なもの

  • ネットワーク上で稼働しており、アクセス可能なKomgaサーバー
  • Komgaのユーザー名とパスワード（またはAPIキー）
  • サーバーのLANアドレス（localhost ではないもの）
  • Androidデバイスにインストールされた Shiori
なぜ localhost ではダメなのか？
localhost は「このデバイス自身」を意味します。スマホでこれを入力すると、サーバーではなくスマホ自身を指してしまいます。ネットワーク上でのサーバーのアドレス（例: 192.168.1.33）を入力する必要があります。

Komga、OPDS 还是 Komga API？首先选择正确的选项

添加服务器时，Shiori 会提供几个快捷填充选项，其中有三个涉及 Komga。它们并不相同：

选项协议类型支持功能
KomgaOPDS v1仅支持浏览与下载
Komga v2OPDS v2仅支持浏览与下载
Komga API ⭐原生 REST API封面、完整图书详情与阅读进度同步

OPDS 是一种通用的目录标准，因此它几乎兼容所有服务器——Calibre、Calibre-Web、Standard Ebooks、Project Gutenberg 等。但通用性也是它的局限所在：它包含的信息仅够列出和下载文件。

而 Komga 的原生 API 了解系列、元数据和阅读进度，因此 Shiori 可以为你展示一个真正的书库，而不是单纯的文件列表，并能将你的阅读进度反馈给 Komga。

除非你有特定原因，否则请始终使用 "Komga API"。

准备工作

  • Komga 正在运行且可以在你的网络中访问
  • 你的 Komga 用户名和密码（或者你更倾向使用的 API 密钥）
  • 服务器的局域网地址（LAN 地址）——而不是 localhost
  • 在 Android 设备上安装好 Shiori
为什么不能使用 localhost？
localhost 代表“本机”。如果在手机上输入它，它指向的是手机本身，而不是你的服务器。你需要的是服务器在局域网中的 IP 地址——例如 192.168.1.33。

Komga, OPDS ou Komga API? Escolha a opção certa primeiro

Quando você adiciona um servidor, o Shiori oferece várias opções de preenchimento rápido, e três delas mencionam o Komga. Elas não são equivalentes:

OpçãoProtocoloRecursos
KomgaOPDS v1Apenas navegação e download
Komga v2OPDS v2Apenas navegação e download
Komga API ⭐REST API NativaCapas, detalhes completos do livro e sincronização do progresso

O OPDS é um padrão de catálogo genérico, por isso funciona com quase qualquer servidor — Calibre, Calibre-Web, Standard Ebooks, Project Gutenberg. Essa generalidade também é o seu limite: ele carrega apenas informações suficientes para listar e baixar um arquivo.

A própria API do Komga conhece séries, metadados e progresso de leitura, permitindo que o Shiori mostre uma biblioteca de verdade em vez de uma lista de arquivos, e informe ao Komga onde você parou de ler.

Use "Komga API" a menos que você tenha um motivo específico para não usar.

O que você precisa

  • O Komga em execução e acessível na sua rede
  • Seu nome de usuário e senha do Komga (ou uma chave de API, se preferir)
  • O endereço de rede local (LAN) do seu servidor — não localhost
  • O Shiori instalado no seu dispositivo Android
Por que não localhost?
localhost significa este dispositivo. Digitado no seu celular, ele aponta para o próprio celular, não para o seu servidor. Você precisa do endereço que seu servidor possui na sua rede — algo como 192.168.1.33.

Si tienes Komga en casa, toda tu biblioteca ya vive en tu propio servidor; sin embargo, leerla en el teléfono suele significar abrir una pestaña del navegador o usar una aplicación que solo muestra una lista básica de nombres de archivo sin portadas.

Shiori se conecta directamente a Komga. Si lo configuras de la forma correcta, obtendrás tus portadas, autores, la estructura de las series y la sincronización de tu posición de lectura con el servidor. Consejos Prácticos y Preguntas Frecuentes (FAQ)

Can I read my downloaded Komga books completely offline?
Yes. Tap the cloud icon before a flight or commute with poor signal; the book lands directly on your normal Shiori bookshelf, complete with TTS narration, custom fonts, highlights and notes.
หนังสือที่ดาวน์โหลดจาก Komga สามารถอ่านแบบออฟไลน์ได้หรือไม่?
อ่านได้ 100% ครับ เพียงแตะไอคอนรูปก้อนเมฆเพื่อดาวน์โหลดก่อนออกเดินทาง หนังสือจะถูกบันทึกลงในชั้นหนังสือหลักของ Shiori พร้อมให้ใช้งานทั้งเสียงอ่านสังเคราะห์ TTS ไฮไลต์ และการจดโน้ตได้โดยไม่ต้องต่อเน็ต
ダウンロードした本は完全オフラインで読めますか？
はい。飛行機に乗る前などにクラウドアイコンをタップしてダウンロードしておけば、通常の本棚に保存され、オフラインでもTTS音声読み上げやハイライト、メモを存分に活用できます。
下载的 Komga 图书支持完全离线阅读吗？
完全支持。在出行或无网络环境下，只需提前点击云端下载图标，图书就会保存到 Shiori 常规书架中，离线同样支持语音朗读（TTS）与高亮笔记。
Posso ler os livros baixados do Komga totalmente off-line?
Sim. Toque no ícone de nuvem antes de viajar; o livro vai direto para a sua estante do Shiori com suporte total a TTS, destaques e anotações sem internet.
¿Puedo leer los libros descargados de Komga sin conexión?
Sí. Pulsa el icono de la nube antes de viajar; el libro se guardará en tu estantería habitual de Shiori con soporte completo para voz (TTS), subrayados y notas sin conexión.
How does search work inside Komga catalogs?
The search box queries Komga directly on the server, not just the visible items on screen. This lets you quickly locate any title across thousands of books in seconds.
การค้นหาหนังสือในแคตตาล็อก Komga ทำงานอย่างไร?
ช่องค้นหาจะส่งคำค้นหาไปสืบค้นบนเซิร์ฟเวอร์ Komga โดยตรง ไม่ได้ค้นหาแค่รายการที่แสดงอยู่บนหน้าจอ ทำให้ค้นหาหนังสือเล่มที่ต้องการจากคลังขนาดใหญ่ที่มีหนังสือหลายพันเล่มได้อย่างรวดเร็ว
Komgaカタログ内での検索機能はどのように動作しますか？
検索ボックスは画面上の表示項目だけでなく、Komgaサーバー全体を直接検索します。膨大な蔵書の中から目的の作品を瞬時に見つけることができます。
在 Komga 书库中的搜索功能是如何运作的？
搜索框会直接向 Komga 服务器发起检索，而不仅限于当前屏幕加载的内容，即便藏书成千上万也能秒级定位。
Como funciona a busca dentro do catálogo do Komga?
A caixa de busca consulta diretamente o servidor Komga, não apenas os itens visíveis na tela, facilitando encontrar títulos em bibliotecas com milhares de volumes.
¿Cómo funciona la búsqueda en el catálogo de Komga?
El cuadro de búsqueda consulta directamente al servidor Komga, no solo los elementos visibles, lo que permite localizar cualquier título en segundos entre miles de libros.
How can I access Komga when reading away from home?
A LAN address (like 192.168.1.33) works within your home Wi-Fi. For remote access outside home, connect through a VPN back to your network (e.g. WireGuard, Tailscale) or configure a secure reverse proxy with HTTPS.
ต้องการเชื่อมต่อ Komga เมื่ออยู่นอกบ้านต้องทำอย่างไร?
ที่อยู่ LAN (เช่น 192.168.1.33) จะใช้งานได้เฉพาะในเครือข่าย Wi-Fi บ้าน หากต้องการอ่านนอกบ้าน แนะนำให้ต่อ VPN กลับมาที่บ้าน (เช่น WireGuard หรือ Tailscale) หรือตั้งค่า Reverse Proxy ร่วมกับ HTTPS ครับ
外出先からKomgaにアクセスして読むには？
LANアドレス（例: 192.168.1.33）は自宅Wi-Fi内専用です。外出先からアクセスする場合は、VPN（WireGuardやTailscale等）で自宅NWに接続するか、HTTPS付きのリバースプロキシを経由して接続してください。
在外出时如何访问家中的 Komga 书库？
局域网 IP（如 192.168.1.33）仅在连接家庭 Wi-Fi 时有效。在外阅读建议配置 VPN（如 WireGuard、Tailscale）连接回家中局域网，或配置带 HTTPS 的反向代理。
Como acessar o Komga quando estiver fora de casa?
O endereço LAN funciona apenas no Wi-Fi doméstico. Para acesso externo, utilize uma VPN para sua rede (como WireGuard ou Tailscale) ou configure um proxy reverso seguro com HTTPS.
¿Cómo puedo acceder a Komga fuera de casa?
La dirección LAN solo funciona dentro de tu Wi-Fi. Para acceder desde el exterior, usa una VPN hacia tu red doméstica (como WireGuard o Tailscale) o un proxy inverso con HTTPS.
