# วิธีเชื่อมต่อ Komga เข้ากับ Shiori บน Android (พร้อมภาพปกและการซิงค์ความคืบหน้าการอ่าน)

หากคุณรัน **Komga** ไว้ที่บ้าน คลังหนังสือทั้งหมดของคุณจะอยู่บนเซิร์ฟเวอร์ส่วนตัวอยู่แล้ว — แต่การอ่านบนโทรศัพท์มักจะต้องเปิดผ่านเว็บเบราว์เซอร์หรือแอปที่แสดงเพียงรายชื่อไฟล์เปล่าๆ โดยไม่มีภาพปก

Shiori สามารถเชื่อมต่อกับ Komga ได้โดยตรง หากตั้งค่าอย่างถูกต้อง คุณจะได้ทั้งภาพปก รายชื่อผู้แต่ง โครงสร้างซีรีส์ และตำแหน่งการอ่านที่ซิงค์กลับไปยังเซิร์ฟเวอร์ คู่มือนี้จะแนะนำขั้นตอนอย่างละเอียด และที่สำคัญที่สุดคือ ควรเลือกตัวเลือก Komga ตัวไหนจากทั้งหมด 3 ตัวเลือกใน Shiori

## Komga, OPDS หรือ Komga API? เลือกตัวเลือกที่ถูกต้องก่อนเป็นอันดับแรก

เมื่อคุณเพิ่มเซิร์ฟเวอร์ Shiori จะมีตัวเลือกเติมข้อมูลด่วนให้เลือกหลายแบบ ซึ่งในนั้นมี 3 ตัวเลือกที่พูดถึง Komga แต่ละตัวเลือกไม่ได้เหมือนกัน:

* **Komga** — เชื่อมต่อผ่าน **OPDS v1** สำหรับเรียกดูและดาวน์โหลดเท่านั้น
* **Komga v2** — เชื่อมต่อผ่าน **OPDS v2** สำหรับเรียกดูและดาวน์โหลดเท่านั้นเช่นกัน
* **Komga API** — เชื่อมต่อผ่าน **REST API หลักของ Komga** โดยตรง ตัวเลือกนี้จะช่วยเพิ่ม **ภาพปก รายละเอียดหนังสือแบบครบถ้วน และการซิงค์ความคืบหน้าการอ่าน**

OPDS เป็นมาตรฐานแคตตาล็อกทั่วไป จึงใช้งานได้กับเซิร์ฟเวอร์เกือบทุกประเภท ไม่ว่าจะเป็น Calibre, Calibre-Web, Standard Ebooks หรือ Project Gutenberg แต่ความครอบคลุมทั่วไปนี้ก็คือข้อจำกัดเช่นกัน เพราะมันส่งข้อมูลเพียงพอสำหรับการแสดงรายการและดาวน์โหลดไฟล์เท่านั้น

API ของ Komga โดยเฉพาะนั้นเข้าใจเรื่องซีรีส์ ข้อมูลเมทาดาตา และความคืบหน้าการอ่าน Shiori จึงสามารถแสดงคลังหนังสือจริงๆ แทนที่จะเป็นแค่รายการไฟล์ และยังแจ้ง Komga ได้ว่าคุณอ่านค้างไว้ที่ตรงไหน

**แนะนำให้เลือก "Komga API" เว้นแต่คุณจะมีเหตุผลเฉพาะเจาะจงในการเลือกตัวเลือกอื่น**

## สิ่งที่คุณต้องเตรียม

* Komga ที่กำลังทำงานและสามารถเข้าถึงได้บนเครือข่ายของคุณ
* **ชื่อผู้ใช้และรหัสผ่าน** Komga ของคุณ (หรือ API key หากคุณสะดวกใช้มากกว่า)
* **ที่อยู่ LAN** ของเซิร์ฟเวอร์ — ไม่ใช่ `localhost`
* แอป Shiori ที่ติดตั้งอยู่บนอุปกรณ์ Android ของคุณ

> **ทำไมถึงไม่ใช้ `localhost`?** `localhost` หมายถึง *อุปกรณ์เครื่องนี้* หากพิมพ์ลงในโทรศัพท์ จะเป็นการชี้กลับมาที่ตัวโทรศัพท์เอง ไม่ใช่เซิร์ฟเวอร์ของคุณ คุณต้องใช้ที่อยู่ IP ที่เซิร์ฟเวอร์ได้รับในเครือข่ายของคุณ เช่น `192.168.1.33`

## ขั้นตอนที่ 1 — เปิดรายการ Library Server (เซิร์ฟเวอร์คลังหนังสือ)

ในแอป Shiori ให้แตะที่แถบ **Collections** ที่เมนูด้านล่าง สกรอลล์ลงมาที่ส่วน **Library Server** แล้วแตะปุ่ม **+** ทางด้านขวา

![แท็บ Collections ใน Shiori แสดงส่วน Library Server พร้อมปุ่มเพิ่ม](01-collections-library-server.jpg)

นี่คือศูนย์รวมของคลังหนังสือออนไลน์ทุกประเภท ไม่ว่าจะเป็นแคตตาล็อก OPDS, Kavita, S3 buckets หรือ WebDAV ดังนั้นเมื่อเพิ่ม Komga แล้ว Komga จะไปปรากฏอยู่เคียงข้างกับแหล่งข้อมูลอื่นๆ ของคุณ

## ขั้นตอนที่ 2 — ทำความรู้จักหน้า Add Library Server

หน้า **Add Library Server** จะมีช่องใส่ชื่อ, URL แคตตาล็อก, แถบปุ่มเติมข้อมูลด่วน (quick-fill chips) และส่วนเข้าสู่ระบบแบบไม่บังคับ

![หน้า Add Library Server แสดงปุ่มเติมข้อมูลด่วนและข้อความช่วยเหลือประเภทเซิร์ฟเวอร์ที่รองรับ](02-add-library-server-form.jpg)

เมื่อสกรอลล์ลงมา Shiori จะแสดงคำอธิบายประเภทเซิร์ฟเวอร์ที่รองรับแต่ละแบบ รวมถึงรูปแบบ URL ที่ถูกต้อง ควรอ่านทำความเข้าใจสักครั้ง ซึ่งเป็นข้อมูลเดียวกับที่ใช้อธิบายในบทความนี้

## ขั้นตอนที่ 3 — ใส่ที่อยู่เซิร์ฟเวอร์ แล้วแตะ "Komga API"

ลำดับขั้นตอนตรงนี้มีความสำคัญ ข้อความแนะนำเหนือปุ่มชิประบุว่า *"type the host, then tap your server"* (พิมพ์โฮสต์ จากนั้นแตะเลือกเซิร์ฟเวอร์ของคุณ):

1. พิมพ์เฉพาะที่อยู่เซิร์ฟเวอร์ของคุณลงในช่อง **Catalog URL** — ตัวอย่างเช่น `192.168.1.33`
2. จากนั้นแตะที่ปุ่ม **Komga API**

Shiori จะแปลงข้อความที่คุณพิมพ์ให้อยู่ในรูปแบบ URL ฉบับเต็มที่ Komga ต้องการโดยอัตโนมัติ:

```
http://192.168.1.33:25600/api/v1
```

`25600` คือพอร์ตเริ่มต้นของ Komga หากคุณมีการเปลี่ยนพอร์ต ให้แก้ไขตัวเลขให้ถูกต้อง — ภาพหน้าจอด้านล่างแสดงเป็น `25601` เนื่องจากเซิร์ฟเวอร์ที่ใช้สาธิตในคู่มือนี้รันอยู่บนพอร์ตที่ตั้งค่าไว้เป็นพิเศษ

จากนั้นกรอกข้อมูลในส่วน **Sign-in**: ชื่อผู้ใช้และรหัสผ่าน Komga ของคุณ (หรือจะเว้นช่องชื่อผู้ใช้ไว้ แล้ววาง Komga API key ลงในช่องที่สองแทนก็ได้ Shiori รองรับทั้งสองแบบ)

![แบบฟอร์มที่กรอกข้อมูลสมบูรณ์พร้อม URL ของ Komga API และข้อมูลเข้าสู่ระบบ](03-komga-api-url-and-signin.jpg)

ตั้งชื่อเซิร์ฟเวอร์ที่ด้านบนเพื่อให้จำได้ง่าย และเลือกไอคอนตามต้องการ

## ขั้นตอนที่ 4 — ทดสอบการเชื่อมต่อก่อนบันทึก

แตะที่ **Test connection** (ทดสอบการเชื่อมต่อ) นี่คือขั้นตอนที่ไม่ควรข้าม เพราะระบบจะตรวจสอบว่าที่อยู่ พอร์ต และข้อมูลประจำตัวทั้งหมดถูกต้องหรือไม่ *ก่อน* คุณจะกดบันทึก

![รายงานผลการทดสอบการเชื่อมต่อ: Connected — Komga (REST API)](04-test-connection-connected.jpg)

ข้อความที่คุณควรเห็นคือ:

```
Connected — Komga (REST API)
```

ข้อความนี้ยืนยันสองเรื่องพร้อมกัน — นั่นคือ Shiori สามารถเชื่อมต่อถึงเซิร์ฟเวอร์ได้ และตรวจพบ **REST API หลัก** โดยไม่ได้ย้อนกลับไปใช้แค่แคตตาล็อกธรรมดา หากแสดงข้อความอื่น คุณจะไม่ได้รับภาพปกและการซิงค์ความคืบหน้าการอ่าน

หากการทดสอบล้มเหลว ให้ตรวจสอบตามลำดับดังนี้:

* **Timed out / cannot reach** — IP ไม่ถูกต้อง หรือโทรศัพท์ไม่ได้เชื่อมต่อเครือข่ายเดียวกับเซิร์ฟเวอร์ ให้ตรวจสอบว่าทั้งสองเครื่องเชื่อมต่อ Wi-Fi เดียวกันหรือไม่
* **Unauthorized** — ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง ชื่อผู้ใช้ของ Komga มักจะเป็นที่อยู่อีเมลเต็ม
* **Connected, but not as REST API** — ส่วน `/api/v1` ของ URL ขาดหายไป หรือระบุพอร์ตผิด

จากนั้นแตะ **Save** (บันทึก) ที่มุมขวาบน

## ขั้นตอนที่ 5 — เซิร์ฟเวอร์ของคุณจะปรากฏในรายการ

ตอนนี้ Komga จะเข้ามาอยู่ในรายการ **Library Server** พร้อมไอคอนแม่กุญแจ ซึ่งแสดงว่ามีการบันทึกข้อมูลประจำตัวไว้เรียบร้อยแล้ว

![เซิร์ฟเวอร์ Komga ที่บันทึกไว้ในรายการ Library Server โดยมีการซ่อน URL ไว้](05-komga-in-library-server-list.jpg)

จะสังเกตเห็นว่า Shiori ซ่อนที่อยู่เซิร์ฟเวอร์ในรายการนี้ไว้ ซึ่งเป็นความตั้งใจออกแบบเพื่อไม่ให้โครงสร้างเครือข่ายภายในของคุณแสดงบนหน้าจอเมื่อยื่นโทรศัพท์ให้คนอื่นดูหรือแคปหน้าจอแชร์

## ขั้นตอนที่ 6 — เรียกดูคลังหนังสือของคุณ

แตะที่เซิร์ฟเวอร์เพื่อเปิดใช้งาน คุณจะพบกับคลังหนังสือ Komga ช่องค้นหาที่ส่งคำค้นหาไปยังแคตตาล็อกโดยตรง และตัวเลือกการจัดเรียง

![การเรียกดูแคตตาล็อก Komga แสดงคลังหนังสือและช่องค้นหาแคตตาล็อก](06-browse-komga-catalog.jpg)

แถบนำทาง (Breadcrumbs) ด้านบนจะแสดงตำแหน่งปัจจุบันของคุณ ช่วยให้คุณย้อนกลับไปหลายระดับได้ในแตะเดียวโดยไม่ต้องกดปุ่มย้อนกลับซ้ำๆ

## ขั้นตอนที่ 7 — ภาพปก รายชื่อผู้แต่ง และการกดอ่านในแตะเดียว

เมื่อเปิดเข้ามาในคลังหนังสือ คุณจะเห็นประโยชน์ของการใช้ REST API หลัก:

![รายการหนังสือแสดงภาพปก ชื่อเรื่อง ผู้แต่ง ฟอร์แมตไฟล์ และขนาดไฟล์](07-books-with-covers-and-authors.jpg)

หนังสือทุกเล่มจะแสดง **ภาพปก**, **ชื่อเรื่อง**, **ผู้แต่ง**, **ฟอร์แมต** และ **ขนาดไฟล์** — ซึ่งดึงมาจากข้อมูลเมทาดาตาของ Komga โดยตรง ในแต่ละแถบจะมี 2 การทำงาน:

* **Read** (อ่าน - ไอคอนรูปหนังสือ) — เริ่มอ่านหนังสือ
* **Download** (ดาวน์โหลด - ไอคอนรูปก้อนเมฆ) — บันทึกไฟล์ไว้ในเครื่องสำหรับอ่านแบบออฟไลน์

และเนื่องจากคุณเชื่อมต่อผ่าน REST API ตำแหน่งการอ่านของคุณจะถูกส่งกลับไปยัง Komga หากคุณอ่านค้างไว้ครึ่งบทบนโทรศัพท์ Komga จะรับรู้ข้อมูลนี้ ทำให้เมื่อคุณเปลี่ยนไปใช้อุปกรณ์เครื่องอื่น ก็สามารถอ่านต่อจากจุดเดิมได้ทันที

## ข้อแนะนำเพิ่มเติม

* **หนังสือที่ดาวน์โหลดสามารถอ่านออฟไลน์ได้ตลอดเวลา** แตะไอคอนก้อนเมฆก่อนขึ้นเครื่องบินหรือก่อนเดินทางผ่านจุดที่มีสัญญาณอินเทอร์เน็ตไม่ดี หนังสือจะถูกจัดเก็บไว้ในชั้นหนังสือปกติของคุณ
* **ช่องค้นหาเป็นการค้นหาบนเซิร์ฟเวอร์ ไม่ใช่แค่สิ่งที่แสดงอยู่บนหน้าจอ** ระบบจะส่งคำค้นหาไปที่ Komga โดยตรง ซึ่งมีประโยชน์มากเมื่อคลังหนังสือของคุณมีขนาดใหญ่เกินกว่าจะสกรอลล์หา
* **ต้องการอ่านนอกบ้าน?** ขั้นตอนเหล่านี้ใช้ที่อยู่ LAN ซึ่งใช้งานได้เฉพาะภายในเครือข่ายบ้านของคุณเท่านั้น การเข้าถึง Komga จากภายนอกจำเป็นต้องเชื่อมต่อผ่าน VPN กลับมายังเครือข่าย หรือใช้ reverse proxy ร่วมกับ HTTPS — ซึ่งทั้งสองวิธีปลอดภัยกว่าการเปิด Komga สู่โลกอินเทอร์เน็ตโดยตรง
* **การเพิ่มเซิร์ฟเวอร์เครื่องที่สองใช้ขั้นตอนเดียวกัน** ไม่ว่าจะเป็น Kavita, Calibre-Web, แคตตาล็อก OPDS, WebDAV หรือ S3 ต่างก็ใช้หน้านี้ในการตั้งค่า และ Shiori จะตรวจหาประเภทเซิร์ฟเวอร์ให้คุณโดยอัตโนมัติ

Komga ช่วยให้คุณควบคุมหนังสือทั้งหมดบนฮาร์ดแวร์ที่เป็นของคุณเอง การเชื่อมต่อกับ Shiori ผ่าน API หลักจะทำให้คุณได้รับประสบการณ์ที่ดีที่สุดบนโทรศัพท์มือถือ โดยได้ทั้งภาพปก เมทาดาตา และตำแหน่งการอ่าน โดยไม่ต้องมอบคลังหนังสือของคุณไปไว้บนคลาวด์ของผู้อื่น

ดาวน์โหลด Shiori เชื่อมต่อไปยังเซิร์ฟเวอร์ Komga ของคุณ แล้วอ่านต่อจากจุดที่ค้างไว้ได้เลย
