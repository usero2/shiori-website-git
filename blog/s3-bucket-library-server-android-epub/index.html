If you love keeping your ebook collection safely stored in cloud object storage, Shiori gives you the freedom to browse and read it directly. Simply point the app at your bucket address, and your entire library appears as organized, browsable folders ready to stream or download — no complex web servers, no third-party sync apps, and no middlemen. It works natively with Amazon S3 as well as any service that speaks the S3 standard: MinIO, Cloudflare R2, Wasabi, and DigitalOcean Spaces.

What Makes an S3 Library Server So Convenient?

S3 object storage has become the global standard for cloud storage because it is fast, durable, and reliable. Shiori communicates with it natively: signing authentication requests securely on your device, displaying your bucket contents in clean folders, and letting you download any EPUB, PDF, or CBZ with a single tap. Your books always remain under your full ownership in your own storage; Shiori simply serves as your personal reader.

What You Will Need to Get Started

  • A cloud bucket containing your books (EPUB, PDF, or CBZ files).
  • The Bucket Address URL (for instance, https://my-books.s3.ap-southeast-1.amazonaws.com/ or a custom MinIO path like https://minio.example.com/my-books/ebooks/).
  • An Access Key and Secret Key for private buckets (or leave credentials empty if your bucket is public).

Complete Privacy — Your Books, Your Storage

Because Shiori establishes a direct, private connection between your phone and your cloud bucket, you maintain absolute control over your digital library. Whether you host a private MinIO server at home on a Raspberry Pi, take advantage of Cloudflare R2's generous free tier with zero egress fees, or store rare volumes in an AWS bucket — the setup process is delightfully identical.

1Open Collections → Library Server

Go to the Collections tab and find the Library Server section. Tap the + button to add a new server. (Any existing servers are listed here with sensitive details safely masked.)

1ไปที่แท็บ Collections → Library Server

เปิดแท็บ Collections (คอลเลกชัน) เลื่อนลงมาที่หัวข้อ Library Server แล้วแตะปุ่ม + เพื่อเพิ่มเซิร์ฟเวอร์ใหม่ (เซิร์ฟเวอร์เดิมที่เคยเพิ่มไว้จะแสดงที่นี่พร้อมปิดบังข้อมูลสำคัญเพื่อความปลอดภัย)

1「コレクション」→「ライブラリサーバー」を開く

Collections（コレクション） タブを開き、Library Server（ライブラリサーバー） セクションを見つけます。+ ボタンをタップして新しいサーバーを追加します。（登録済みのサーバーもここに安全にマスクされて一覧表示されます。）

1进入“藏书” → “书库服务器”

打开 Collections（藏书） 标签页，找到 Library Server（书库服务器） 分组，点击 + 按钮添加新服务器。（已添加的服务器也会在此列出，并妥善隐藏敏感地址信息。）

1Abra Coleções → Servidor de Biblioteca

Acesse a aba Collections (Coleções) e localize a seção Library Server. Toque no botão + para adicionar um novo servidor. (Seus servidores existentes também ficam listados aqui com dados protegidos.)

1Abre Colecciones → Servidor de Biblioteca

Ve a la pestaña Collections (Colecciones) y busca la sección Library Server. Pulsa el botón + para añadir un servidor nuevo. (Tus servidores actuales aparecerán listados con sus datos protegidos.)

2Enter the Bucket URL and Credentials

Paste your Bucket Address into the Catalog URL field. Put your Access Key in the Username box and your Secret Key in the Password box. Shiori intelligently recognizes S3 URLs — the password label automatically switches to “Secret access key.” For public buckets, simply leave the login fields empty.

2กรอกที่อยู่ Bucket URL และรหัสผ่าน

วาง ที่อยู่ Bucket ลงในช่อง Catalog URL จากนั้นใส่ Access Key ในช่อง Username และใส่ Secret Key ในช่อง Password ระบบของ Shiori จะตรวจจับว่าเป็น S3 อัตโนมัติ โดยช่องรหัสผ่านจะเปลี่ยนป้ายชื่อเป็น “Secret access key” ให้ทันที (หากเป็น Bucket สาธารณะ ไม่ต้องกรอกชื่อผู้ใช้และรหัสผ่าน)

2バケットURLと認証情報を入力

Catalog URL欄に バケットのアドレス を貼り付けます。ユーザー名欄に Access Key、パスワード欄に Secret Key を入力します。ShioriがS3アドレスを自動認識し、パスワード欄の表記が “Secret access key” に変化します。（公開バケットの場合は空欄のままで構いません。）

2输入存储桶 URL 与访问密钥

将 存储桶地址 粘贴至 Catalog URL 输入框中。在 Username 处填入 Access Key，在 Password 处填入 Secret Key。Shiori 会自动识别 S3 协议，密码栏标签会自动切换为 “Secret access key”。（若为公开存储桶，认证信息留空即可。）

2Insira a URL do Bucket e as Chaves de Acesso

Cole o endereço do bucket no campo Catalog URL. Coloque sua Access Key no campo Username e a Secret Key no campo Password. O Shiori detecta a URL S3 automaticamente — o campo de senha mudará o rótulo para “Secret access key.” Para buckets públicos, deixe os campos de login em branco.

2Introduce la URL del Bucket y tus Claves

Pega la dirección del bucket en el campo Catalog URL. Escribe tu Access Key en Username y tu Secret Key en Password. Shiori reconoce automáticamente la dirección S3 y cambiará el texto del campo a “Secret access key.” Si tu bucket es público, deja los campos de inicio de sesión vacíos.

打开服务器后，存储桶内的图书将以结构清晰的文件夹形式呈现。点击任意图书右侧的 下载 图标即可将其保存至本地书架；已下载的图书会贴心标注 “Already on your bookshelf”。顶部还支持全书库快速搜索。

💡 实用小贴士
如果您在局域网内自建了 MinIO 服务，请使用电脑的局域网 IP（如 192.168.1.x）而非 localhost，因为 Shiori 运行在您的手机端。
4Navegue pelas Pastas e Baixe Seus Livros

Ao abrir o servidor, seu bucket é exibido em pastas estruturadas. Toque no ícone de Download em qualquer livro para salvá-lo na sua estante local; títulos já baixados exibirão “Already on your bookshelf.” Você também pode pesquisar títulos no topo do catálogo.

💡 Dica Útil
Executando o MinIO ou outro servidor na sua rede local? Use o endereço IP da rede local (ex: 192.168.1.x) em vez de localhost, pois o app roda no seu smartphone.
4Explora las Carpetas y Descarga tus Libros

Abre el servidor y verás el contenido de tu bucket organizado en cómodas carpetas. Toca el icono de Descarga en cualquier título para guardarlo en tu estantería; los libros ya descargados mostrarán “Already on your bookshelf.” Además, puedes buscar cualquier título desde la barra superior.

💡 Consejo Práctico
¿Utilizas MinIO en tu red local? Usa la dirección IP de tu red local (por ejemplo, 192.168.1.x) en lugar de localhost, ya que Shiori se ejecuta en tu teléfono.
