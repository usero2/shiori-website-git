Rewrite What You Read
Text Replacement and Regex, End to End

🔤

Every ebook has something you would change. A translator's spelling you dislike, a name your text-to-speech voice mangles, footnote markers that interrupt the narration, three exclamation marks where one would do. Shiori's Text Replacement fixes all of it — across every book, without editing a single file.

There are two lists, and the difference between them is the whole idea.

Visual vs TTS: The One Thing to Understand

VisualTTS
Changes the page you see✅ Yes❌ No
Changes what the voice reads✅ Yes✅ Yes
Typical usespelling, clutter, renamingpronunciation, abbreviations

In the app's own words: a Visual rule "replaces text in reader view and before TTS reads," while a TTS rule "replaces text only when sent to TTS — not shown in reader."

So: if you want to see the change, use Visual. If you only want to hear it, use TTS. A pronunciation hack like Rodya → Rod-ya belongs on the TTS list, where it will never disfigure the page.

Neither list ever touches your EPUB file. Rules are applied on the fly, every time a chapter renders or a paragraph is spoken — so deleting a rule restores the original wording instantly.

Anatomy of a Rule

  • Find (from) — the text to look for. With Use Regex on, this field is relabelled Pattern (regex).
  • Replace with (to) — what to put in its place. Leave it empty to delete the match.
  • Use Regex — plain text or pattern. The ? beside it opens a built-in cheat sheet.
  • Order — rules run in this order, each one working on the result of the last.
  • On/off switch — on every row, so you can park a rule without deleting it.
  • ▶ buttons — hear either field spoken aloud, in the preview voice shown underneath.

Step-by-Step Guide (12 Steps)

1Open Settings → Visual & TTS Replacement

The entry sits in Settings, described as "Rewrite text shown in the reader or spoken by TTS." One screen holds both lists as swipeable tabs.

2Meet the List

Each tab opens with its master switch, an item count, and the rules themselves. Every row shows its order number, an on/off switch, the find → replace pair, an Rx tag if it is a regex, and edit and delete icons.

The magnifier in the top bar filters a long list; the two arrows beside it export and import.

3Add a Plain-Text Rule

Tap +, type what to find and what to replace it with, then Save. Plain rules are literal and case-sensitive, and they replace every occurrence in every book.

4Turn On Use Regex

Tick Use Regex and the first field becomes Pattern (regex) — a small label change that tells you the text is now being read as a pattern.

Here Mr\. means "the letters M, r, and a real dot": the backslash stops . from meaning any character, which would also have matched Mrs.

5Open the Cheat Sheet

The ? next to the checkbox opens How to use Regex: a symbol summary and six worked examples you can copy straight into the fields. It is the fastest way to remember what {3,} or [0-9]+ does while you are mid-rule.

6Let the Safety Check Catch Your Mistakes

Shiori analyses the pattern as you type. Write $1 when your pattern has no groups and you get "This rule can't work — $1 points at a group this pattern doesn't have, so the rule would be skipped every time," with Save greyed out until you fix it.

Patterns that are merely slow get a warning instead of a block — you stay in charge, but you are told.

7See It in the Reader

Open any book and the visual rules are already applied. Ours turns every "Raskolnikov" into "Rodya" throughout Crime and Punishment — hundreds of occurrences, and not one byte of the file changed.

8Search Sees the Rewritten Text Too

Search inside the book and the results come back in the replaced wording — because the text you search is the text you read. Rules and search never disagree with each other.

9Create a Rule Straight From the Page

You do not have to go back to Settings. Select a word while reading and the selection menu offers Replace — alongside Read, Bookmark, Highlight, Translate, Aloud and TTS preview.

10Give TTS Its Own Rule — and Its Own Language

The dialog opens with Find already filled in from your selection, plus a Visual / TTS radio pair to decide which list it joins.

Choose TTS and a Voice language row appears: Global, or one specific voice language. A language-scoped rule only fires on passages spoken in that voice, so a Thai pronunciation fix never interferes with the English narrator.

11Preview What the Voice Will Say

Select text and tap TTS preview. Shiori shows the original above and the spoken version below — here Rodya → Rod-ya — with an Aloud button so you can hear the result before committing to it.

This is the fastest way to debug a rule: real text from a real book, every rule applied, in one dialog.

12Manage the TTS List by Language

The TTS tab carries filter chips with live counts — Global plus each enabled voice language — and groups the list under headers that each have their own switch. Tap a chip to include or exclude that group; the choice is remembered between sessions.

A Regex Cookbook

The six examples built into the app:

PatternReplace withWhat it does
colou?rcolor? makes the previous letter optional — matches color and colour
(ha){3,}haha{3,} repeats the group three or more times — shortens laughter of any length
[0-9]+(empty)any run of digits; an empty replacement deletes the match
[!?]{2,}!collapses !!! or ?!? into a single !
Mr\.Mister\ before . matches a real dot, not "any character"
(\w+) (\w+)$2 $1( ) captures; $1 and $2 reuse the captures — this swaps two words

Three Rules About the Rules

Two engines, one syntax to stay inside. Visual rules are applied by the browser engine inside the page; TTS rules are applied by the app before the words reach the voice. Everything in the tables above works on both sides. Exotic extras — inline flags such as (?i), for instance — may work on one side only, so keep patterns to the common core and use the TTS preview to check.

Quotes are normalised. Curly apostrophes, backticks and full-width quotes are all treated as a plain ' before matching, so you can type an ordinary apostrophe and still match typographic text.

Order matters. Rules run from the top down, each on the output of the one before it. If one rule feeds another, give the first a lower Order number.

The Safety Net

A regex is powerful enough to hang an app, so Shiori guards it at four levels:

  1. While you type — errors (invalid syntax, a bad group reference, a stray $) block Save; warnings (a pattern matching empty text, or one measured as slow) let you save but stay visible.
  2. In the list — a badge marks any rule with an issue, including ones that arrived by import or cloud sync.
  3. At runtime — a rule judged unsafe is skipped rather than run, on the page and on the TTS side alike.
  4. After a crash — if the app ever goes down inside a replacement, both master switches are turned off on the next launch and a banner explains why. Your rules are never deleted.
💡 The master switch is your own version of that.
Each tab's switch reads: "Safe mode: switch off to bypass every rule temporarily — each rule's own on/off state is kept." Perfect for checking whether a rule is behind something odd on the page.

Moving Rules Around

  • Export writes the current tab's rules to a JSON file — enabled states and language groups included.
  • Import reads that JSON back, and still accepts the older tab-separated format.
  • Cloud sync carries rules between your own devices with a review banner — "From your other devices: 7 new, 0 deleted" — so nothing is added behind your back.

Frequently Asked Questions

Does a replacement change my EPUB file?
No. Rules are applied as the page renders or as text is sent to the voice. The file on disk is untouched, and deleting a rule restores the original wording instantly.
Can a rule apply to only one book?
Rules are global across your library. Use the row switch to park one you only need occasionally, or the master switch to bypass a whole list.
Are rules case-sensitive?
Yes, both plain and regex. Match the case you actually want, or use a character class such as [Tt]he to cover both.
Why is my regex not matching?
Check three things: the Use Regex box is actually ticked; special characters such as . ? + ( [ are escaped with \ when you mean them literally; and no later rule is undoing the first one.
How do I delete text instead of replacing it?
Leave Replace with empty and every match is removed — the standard trick for stripping footnote markers.
What is the difference between the ▶ buttons and TTS preview?
The ▶ buttons speak a single field so you can hear how a replacement sounds on its own. TTS preview takes real text from the book and shows the finished spoken result with every rule applied.
Can I use this for text-to-speech in other languages?
Yes — that is what the voice-language groups are for. See also our guides to reading Japanese books and the multi-language translation features.
