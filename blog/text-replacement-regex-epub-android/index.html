Visual vs TTS: The One Thing to Understand

VisualTTS
Changes the page you see✅ Yes❌ No
Changes what the voice reads✅ Yes✅ Yes
Typical usespelling, clutter, renamingpronunciation, abbreviations

In the app's own words: a Visual rule "replaces text in reader view and before TTS reads," while a TTS rule "replaces text only when sent to TTS — not shown in reader."

So: if you want to see the change, use Visual. If you only want to hear it, use TTS. A pronunciation hack like Rodya → Rod-ya belongs on the TTS list, where it will never disfigure the page.

Neither list ever touches your EPUB file. Rules are applied on the fly, every time a chapter renders or a paragraph is spoken — so deleting a rule restores the original wording instantly.

Anatomy of a Rule

  • Find (from) — the text to look for. With Use Regex on, this field is relabelled Pattern (regex).
  • Replace with (to) — what to put in its place. Leave it empty to delete the match.
  • Use Regex — plain text or pattern. The ? beside it opens a built-in cheat sheet.
  • Order — rules run in this order, each one working on the result of the last.
  • On/off switch — on every row, so you can park a rule without deleting it.
  • ▶ buttons — hear either field spoken aloud, in the preview voice shown underneath.

置換ルールの構成要素

  • Order（順序） — ルールの実行順序（上の結果を受けて次のルールが処理）。

Does a text replacement rule modify my actual EPUB file?
No. Rules are applied dynamically in memory when a chapter renders or when text is sent to the TTS voice. The actual file on your device remains completely untouched, and deleting a rule restores the original text immediately.

ไม่เลยครับ กฎทั้งหมดจะทำงานในหน่วยความจำชั่วคราวขณะแสดงผลหน้าหนังสือหรือขณะสังเคราะห์เสียงอ่านเท่านั้น ไฟล์หนังสือจริงในเครื่องจะไม่ถูกแก้ไขใดๆ และเมื่อลบกฎออก ข้อความเดิมจะกลับคืนมาทันที
置換ルールによってEPUBファイル本体は変更されますか？
いいえ、一切変更されません。ルールは画面描画や音声出力の瞬間にメモリ上で適用されます。端末内のファイルは常に保護されており、ルールを削除すれば一瞬で元の表記に戻ります。
文本替换规则会修改 EPUB 源文件吗？
完全不会。所有规则仅在内存渲染与语音合成时实时生效，手机中保存的图书源文件始终保持原样，删除规则即可即刻恢复原文。
A regra de substituição altera o arquivo EPUB real?
Não. As regras operam em tempo real durante a exibição ou leitura em voz alta. O arquivo no disco permanece intacto.
¿Modifica el reemplazo el archivo EPUB original?
No. Las reglas se ejecutan en memoria durante la lectura o reproducción de voz. El archivo permanece inalterado.
Can a replacement rule apply to only one specific book?
Rules are designed to be global across your entire library for maximum convenience. You can use the row toggle switch to easily disable a rule when reading books that don't need it.
สามารถตั้งกฎให้มีผลเฉพาะหนังสือบางเล่มได้ไหม?
ระบบออกแบบให้กฎมีผลทั่วทั้งคลังหนังสือเพื่อความสะดวกรวดเร็วครับ หากมีกฎเฉพาะสำหรับบางเล่ม คุณสามารถแตะสวิตช์เปิด/ปิดหน้าแถวกฎเพื่อพักการใช้งานเมื่ออ่านเล่มอื่นได้ง่ายๆ
特定の1冊だけにルールを適用できますか？
ルールはライブラリ全体で共有される仕様です。不要な本を読む際は、ルール行のスイッチで一時的にOFFにしておくのが便利です。
规则可以仅对某一本书生效吗？
规则采用全局生效机制以提升管理效率。若某条规则仅适用于特定书籍，可通过该行开关随时停用或启用。
Posso aplicar uma regra apenas a um livro específico?
As regras são globais na biblioteca. Use o interruptor da linha para desativar temporariamente quando ler outras obras.
¿Puedo aplicar una regla solo a un libro concreto?
Las reglas son globales en tu biblioteca. Puedes usar el interruptor de fila para pausar una regla cuando leas otros títulos.
Are replacement rules case-sensitive?
Yes, both plain text and regex rules are case-sensitive. Enter the exact casing you want, or use regex character classes such as [Tt]he to match both capitalized and lowercase variations.
กฎการแทนที่คำนึงถึงตัวพิมพ์เล็ก-ใหญ่หรือไม่?
คำนึงถึงครับ (Case-sensitive) ทั้งข้อความธรรมดาและ Regex หากต้องการให้จับคู่ทั้งตัวเล็กและตัวใหญ่ สามารถใช้สูตรอย่าง [Tt]he ได้ครับ
大文字と小文字は区別されますか？
はい、プレーン・正規表現ともに大文字小文字を区別します。両方に一致させたい場合は [Tt]he のように文字クラスをご活用ください。
规则是否区分英文字母大小写？
是的，普通规则与正则规则均区分大小写。如需同时匹配首字母大写与小写，可使用 [Tt]he 等字符集写法。
As regras diferenciam maiúsculas de minúsculas?
Sim. Para cobrir ambas as formas, use classes de caracteres como [Tt]he.
¿Se distinguen mayúsculas y minúsculas?
Sí. Para incluir ambas variantes, puedes recurrir a patrones como [Tt]he.
How do I delete unwanted text instead of replacing it?
Simply leave the Replace with field completely empty. Every match of your find pattern will be cleanly removed — ideal for stripping footnote markers like [12].
ถ้าต้องการลบคำที่ไม่ต้องการทิ้งโดยไม่แทนที่ด้วยอะไรเลย ต้องทำอย่างไร?
เพียงปล่อยช่อง Replace with ให้ว่างไว้ครับ ข้อความที่ตรงกับเงื่อนไขจะถูกลบทิ้งทั้งหมด ซึ่งเป็นวิธีที่นิยมมากในการลบหมายเลขเชิงอรรถอย่าง [12]
置換ではなく、不要な文字列を削除したい場合は？
Replace with 欄を完全に空欄にしてください。一致した文字列がきれいさっぱり削除されます（[12] のような脚注番号の削除に最適です）。
如何直接删除不需要的文字而非替换？
只需将 Replace with 栏完全留空即可。所有匹配项将被彻底移除，非常适合消除 [12] 这类脚注标记。
Como excluir texto indesejado em vez de substituir?
Basta deixar o campo Replace with totalmente vazio. O texto correspondente será removido da leitura.
¿Cómo elimino texto no deseado en lugar de reemplazarlo?
Deja el campo Replace with completamente en blanco. Toda coincidencia será eliminada del texto.
