Whether you manage your library with Calibre, run Calibre-Web on a home server, organize digital comics in Komga, curate light novels in Kavita, or browse classic literature on Project Gutenberg, all of them can share their books through a simple OPDS feed. With Shiori, you can paste that single address and watch it turn into a clean, beautifully organized bookshelf right on your Android device — no cloud accounts, no sync subscriptions, and no uploading your private collection to third-party servers.

What Is OPDS, Exactly?

OPDS stands for Open Publication Distribution System. Think of it as RSS for ebooks: instead of publishing news articles, a server publishes a catalog of books — titles, authors, covers, descriptions, categories and download links — in a standard format that any reading app can understand.

That open standard is what makes it so powerful. The server does not need custom plugins for Shiori, and Shiori works seamlessly with any server that publishes OPDS. Shiori natively supports both OPDS 1.x (the Atom-based XML format) and OPDS 2.0 (the modern JSON-based format), giving you instant access to virtually any catalog.

What You Will Need

  • The catalog URL — the address of the OPDS feed itself, rather than your server's home page (see the handy table below).
  • A username and password — only if your catalog is private. Public catalogs require no login credentials at all.
  • Network access — ensure your phone and server are on the same Wi-Fi network for home servers, or use a public domain/IP if connecting remotely.

Where to Find Your OPDS URL

Here are the standard feed addresses for popular self-hosted servers. Simply replace 192.168.1.10 with your server's actual IP address or domain name.

ServerTypical OPDS address
Calibre (content server)http://192.168.1.10:8080/opds
Calibre-Webhttp://192.168.1.10:8083/opds
Komgahttp://192.168.1.10:25600/opds/v1.2/catalog
Komga (OPDS 2.0)http://192.168.1.10:25600/opds/v2/catalog
Kavitahttp://192.168.1.10:5000/api/opds/YOUR_API_KEY
Project Gutenberg (public)https://www.gutenberg.org/ebooks.opds/

Shiori includes built-in Quick fill buttons for these exact services. Simply enter your host or IP address, tap Calibre, Calibre-Web, Komga, Komga v2, or Kavita, and Shiori fills in the standard port and path automatically.

Kavita is the one slight exception.
Its API key is embedded directly inside the URL. In Kavita, navigate to Account → OPDS URL, paste your personal API key right after /api/opds/, and leave the username and password fields blank in Shiori.

OPDSとは？ その魅力と仕組み

OPDS（Open Publication Distribution System）は、いわば「電子書籍のためのRSS」です。ニュース記事の代わりに、書籍のタイトル、著者名、表紙画像、解説文、カテゴリ、ダウンロードリンクなどの情報を標準規格で配信します。

オープン規格だからこそ、サーバーごとに特別なプラグインを用意する必要がありません。Shioriは広く普及している **OPDS 1.x**（XML/Atomベース）と最新の **OPDS 2.0**（JSONベース）の双方をネイティブサポートしており、世界中のあらゆるカタログとスムーズに接続できます。

什么是 OPDS？为什么它如此强大？

OPDS（Open Publication Distribution System，开放出版物分发系统）好比“电子书专属的 RSS 订阅”。服务器以统一开放的标准格式输出书名、作者、封面、简介、分类及下载链接，任何支持该协议的阅读器均可无缝读取。

这一开放标准赋予了用户极大的自由度。服务器无需为 Shiori 单独开发插件，Shiori 也原生支持 **OPDS 1.x**（基于 Atom/XML）与 **OPDS 2.0**（基于现代 JSON 格式），轻松连接全球各类书库。

Go to the Collections tab and scroll down to the Library Server section. Tap + to add a new catalog. Servers you have already added are listed here with their addresses masked, so a screenshot never leaks your private URL.

1ไปที่แท็บ Collections → Library Server

เปิดแท็บ Collections (คอลเลกชัน) แล้วเลื่อนลงมาที่หัวข้อ Library Server แตะปุ่ม + เพื่อเพิ่มแคตตาล็อกใหม่ (เซิร์ฟเวอร์เดิมที่เคยเพิ่มไว้จะแสดงที่นี่พร้อมปิดบังข้อมูลสำคัญเพื่อความปลอดภัย)

1「コレクション」→「ライブラリサーバー」を開く

Collections（コレクション） タブを開き、Library Server（ライブラリサーバー） セクションまでスクロールします。+ ボタンをタップして新規カタログを追加します（登録済みサーバーのURLはマスク表示されます）。

1进入“藏书” → “书库服务器”

打开 Collections（藏书） 页面，滚动至 Library Server（书库服务器） 分组，点击 + 号添加新书库。（已添加的服务器会在此列出，并妥善隐藏私有地址。）

1Abra Coleções → Servidor de Biblioteca

Acesse a aba Collections (Coleções) e localize a seção Library Server. Toque no + para adicionar um novo catálogo. Seus servidores existentes são listados aqui com URLs protegidas.

1Abre Colecciones → Servidor de Biblioteca

Ve a la pestaña Collections (Colecciones) y dirígete a la sección Library Server. Pulsa el botón + para añadir un nuevo catálogo (las direcciones privadas aparecen enmascaradas por seguridad).

2Name It and Paste the Catalog URL

Type a friendly name, then paste your OPDS address into the Catalog URL field. Not sure of the exact path? Type just the host or IP and tap a Quick fill chip — Calibre, Calibre-Web, Komga, Komga v2, or Kavita — and Shiori completes the rest.

If your catalog is private, fill in Sign-in (optional) with your username and password. For a public catalog, leave both fields empty.

2ตั้งชื่อและวางที่อยู่ Catalog URL

ตั้งชื่อเซิร์ฟเวอร์ตามที่คุณเข้าใจ จากนั้นวางที่อยู่ OPDS ลงในช่อง Catalog URL หากไม่แน่ใจพาร์ท ให้พิมพ์เฉพาะ IP แล้วแตะปุ่ม Quick fill (เช่น Calibre, Komga ฯลฯ) เพื่อเติมพาร์ทให้อัตโนมัติ

หากเป็นเซิร์ฟเวอร์ส่วนตัว ให้กรอก Username และ Password ในส่วน Sign-in (optional) หากเป็นคลังสาธารณะ ปล่อยว่างไว้ได้เลยครับ

2名前をつけてCatalog URLを貼り付け

わかりやすいサーバー名を入力し、Catalog URL 欄にOPDSアドレスを入力します。パスが不明な場合は、ホスト名を入力して Quick fill チップをタップすると自動補完されます。

認証が必要な場合は Sign-in (optional) 欄にユーザー名とパスワードを入力します。公開サーバーの場合は空欄で構いません。

2命名书库并粘贴 Catalog URL

输入自定义名称，在 Catalog URL 处填入 OPDS 地址。若不确定具体路径，只需输入 IP，然后点击 Quick fill 快捷标签即可自动补全。

若是私有书库，请在 Sign-in (optional) 处填写账号密码；若为公开书库则保持留空。

2Dê um Nome e Cole a URL do Catálogo

Digite um nome de identificação e cole o endereço OPDS no campo Catalog URL. Se preferir, digite apenas o IP e use as opções de Quick fill para preencher o caminho automaticamente.

Para catálogos protegidos, preencha o Sign-in (optional) com seu usuário e senha. Para catálogos públicos, deixe em branco.

2Asigna un Nombre y Pega la URL del Catálogo

Escribe un nombre reconocible y pega la dirección OPDS en el campo Catalog URL. Si tienes dudas con la ruta, escribe el host y pulsa en los botones de Quick fill para completarla.

Si tu catálogo requiere credenciales, rellena el apartado Sign-in (optional) con usuario y contraseña. Si es público, déjalo vacío.

3Tap Test Connection, Then Save

Shiori fetches the feed and reports what it found. For a working catalog, you will see “Connected — OPDS catalog.” That confirms the address is reachable, your credentials are valid, and the response is an authentic catalog. Now tap Save.

3แตะ Test Connection แล้วกด Save

Shiori จะทดสอบดึงข้อมูลฟีดและแสดงสถานะ เมื่อเชื่อมต่อถูกต้องจะขึ้นข้อความ “Connected — OPDS catalog” ซึ่งยืนยันว่าที่อยู่ถูกต้องและรหัสผ่านผ่านการอนุมัติเรียบร้อย ให้แตะ Save เพื่อบันทึก

3Test Connection をタップして Save

Shioriがフィードを取得し、接続状態を確認します。正常に疎通すると “Connected — OPDS catalog” と表示されます。確認できたら Save をタップして保存します。

3点击 Test Connection 测试连接并保存

Shiori 会即刻拉取订阅源。若配置正确，界面将提示 “Connected — OPDS catalog”，确认地址与认证无误后，点击 Save 保存。

3Toque em Test Connection e Depois em Save

O Shiori testa o feed e confirma o status. Quando tudo estiver correto, você verá “Connected — OPDS catalog.” Basta tocar em Save para salvar.

3Pulsa Test Connection y Luego Save

Shiori comprobará la conexión al feed. Si todo es correcto, verás el mensaje “Connected — OPDS catalog.” Pulsa en Save para guardar los cambios.

4Need Help with Addresses? Check “Supported servers”

The same screen carries a built-in reference for every server type Shiori supports: OPDS 1.x / 2.0, Komga, Kavita, WebDAV, FTP/FTPS, S3 buckets, DSpace repositories, and the Everything HTTP server — each with ready-to-copy URL examples.

4ดูตัวอย่างพาร์ทได้ใน “Supported servers”

ในหน้านี้มีคู่มือในตัวสรุปตัวอย่าง URL ของเซิร์ฟเวอร์ทุกประเภทที่ Shiori รองรับ ไม่ว่าจะเป็น OPDS 1.x / 2.0, Komga, Kavita, WebDAV, FTP, S3 Bucket, DSpace หรือ Everything HTTP Server ช่วยให้หมดปัญหาเรื่องจำพอร์ตจำพาร์ทไม่ได้

4URLに迷ったら「Supported servers」を確認

設定画面下部には、OPDS 1.x/2.0、Komga、Kavita、WebDAV、FTP、S3バケット、DSpaceなど、対応するすべてのプロトコルのURLサンプルが分かりやすく掲載されています。

4随时查阅“Supported servers”内置指南

界面内置了支持服务器类型的完整示例，涵盖 OPDS 1.x / 2.0、Komga、Kavita、WebDAV、FTP、S3 存储桶与 DSpace 等，助您快速参照端口与路径格式。

4Consulte a Lista de “Supported servers”

A própria tela inclui uma lista de referência com exemplos de URLs para todos os tipos de servidores compatíveis: OPDS 1.x/2.0, Komga, Kavita, WebDAV, FTP, S3 e DSpace.

4Consulta la Guía “Supported servers”

La pantalla incluye una práctica referencia con ejemplos de URL para todos los servidores compatibles: OPDS 1.x/2.0, Komga, Kavita, WebDAV, FTP, buckets S3 y DSpace.

5Open the Server and Browse Your Catalog

Tap your saved server and the catalog opens exactly as its owner organized it — by popularity, series, bookshelves, or languages. Breadcrumbs across the top show where you are, and a single tap takes you back to any level.

A sorting menu beside the search bar lets you reorder any feed by title, date, or file size.

5เปิดเซิร์ฟเวอร์และเลือกดูหมวดหมู่หนังสือ

เมื่อแตะเปิดเซิร์ฟเวอร์ คุณจะเห็นโครงสร้างหมวดหมู่ตามที่เซิร์ฟเวอร์จัดไว้ เช่น แยกตามความนิยม, ตามซีรีส์, ตามชั้นหนังสือ หรือตามภาษา มีแถบ Breadcrumbs ด้านบนบอกตำแหน่ง และมีเมนูเรียงลำดับตามชื่อหรือขนาดไฟล์ได้อย่างอิสระ

5サーバーを開いてカタログを快適に探索

登録したサーバーをタップすると、人気順、シリーズ別、本棚別など、サーバー側で整理されたカテゴリ構造がそのまま展開されます。上部のパンくずリストでいつでも上の階層へ戻れます。

5进入服务器，畅游分类书海

点击进入已保存的书库，即可按热门度、系列丛书、书单分类等清晰目录进行浏览。顶部配有直观的面包屑导航，随时可一键返回上一层。

5Abra o Servidor e Explore o Catálogo

Toque no servidor cadastrado para navegar pelas categorias originais — por popularidade, séries ou estantes. A navegação estruturada no topo permite voltar a qualquer nível facilmente.

5Abre el Servidor y Explora el Catálogo

Pulsa en el servidor guardado para ver las secciones organizadas: por popularidad, series o estanterías. La barra de navegación superior te permite volver a cualquier nivel con un solo toque.

6Tap a Book for Details, Then Download

Every book displays its cover, format badge, and file size. Expand any entry to read full descriptions and subject tags provided by the catalog.

Two action buttons sit on the right: Read now (the book icon) streams the file and opens it instantly, while Download quietly saves it to your bookshelf. Titles you already possess are marked “Already on your bookshelf” so you never download duplicates. Supports EPUB, PDF, FB2, and CBZ/CBR comics.

6แตะดูรายละเอียดและดาวน์โหลดหนังสือ

หนังสือแต่ละเล่มจะแสดงภาพปก, ชนิดไฟล์ และขนาดไฟล์อย่างชัดเจน สามารถกดขยายเพื่ออ่านเรื่องย่อและแท็กหมวดหมู่ได้อย่างครบถ้วน

มี 2 ปุ่มให้เลือกใช้: Read now (ไอคอนหนังสือ) สำหรับเปิดอ่านทันที และ Download สำหรับบันทึกเข้าชั้นหนังสือในเครื่อง เล่มที่เคยโหลดไว้แล้วจะแสดงป้าย “Already on your bookshelf” เพื่อป้องกันการโหลดซ้ำ รองรับทั้ง EPUB, PDF, FB2 และการ์ตูน CBZ/CBR

6詳細情報を確認してワンタップダウンロード

各書籍の表紙、フォーマット、ファイルサイズが表示され、展開すると詳細なあらすじやタグを確認できます。

Read now（本アイコン）で即座に開いて読書を開始できるほか、Download で端末の本棚へ保存できます。保存済みの本には “Already on your bookshelf” と明記されるため重複の心配もありません。

6查看书籍详情，一键下载到本地

每本书均显示封面、格式标签与文件体积，展开可阅读完整的书籍简介与标签信息。

右侧提供双重操作：点击 Read now（书本图标）可即刻在线流式阅读，点击 Download 则可静默下载保存至书架。已下载的书籍贴心标注 “Already on your bookshelf”，杜绝重复下载。

6Veja os Detalhes e Baixe o Livro

Cada livro exibe capa, formato e tamanho. Expanda o item para ler a sinopse completa e as tags do catálogo.

Use Read now para abrir e ler imediatamente ou Download para guardar na sua estante. Títulos já baixados exibem “Already on your bookshelf” para evitar downloads repetidos.

6Consulta los Detalles y Descarga la Obra

Cada entrada muestra portada, formato y tamaño de archivo. Puedes desplegarla para leer la sinopsis completa y las etiquetas del catálogo.

Dispones de dos botones: Read now para abrir el libro de inmediato y Download para guardarlo en tu estantería. Las obras ya descargadas indican “Already on your bookshelf”.

7Enjoy Your Book Offline Anytime

The downloaded book arrives safely on your personal bookshelf as a local file — fully equipped for offline reading, text-to-speech voice narration, highlights, and notes. Its card includes a subtle badge showing its source server, and the card menu's “Where from” action takes you directly back to that catalog whenever you're ready for the next volume.

💡 Pro Tip
Self-hosting at home? Always use your computer's local LAN IP (e.g. 192.168.1.10) rather than localhost, since Shiori runs on your mobile device. And ensure you include the /opds endpoint path.
7อ่านได้ลื่นไหลแบบออฟไลน์ พร้อมฟีเจอร์ครบครัน

หนังสือที่ดาวน์โหลดจะถูกจัดเก็บไว้บนชั้นหนังสือในเครื่องของคุณ พร้อมให้อ่านแบบออฟไลน์ได้ทุกที่ ใช้เสียงอ่าน TTS ไฮไลต์ และจดโน้ตได้ครบถ้วน บนการ์ดหนังสือจะมีป้ายระบุแหล่งที่มา และมีเมนู “Where from” ที่ช่วยพาคุณกลับไปยังแคตตาล็อกเดิมเพื่อดาวน์โหลดเล่มถัดไปได้อย่างสะดวกสบาย

💡 เคล็ดลับนักอ่าน
หากรันเซิร์ฟเวอร์เองที่บ้าน ให้ใช้ IP วงแลน (เช่น 192.168.1.10) แทนการใช้ localhost เพราะแอปทำงานบนมือถือของคุณ และอย่าลืมระบุพาร์ท /opds ต่อท้ายเสมอครับ
7いつでもどこでもオフライン読書を満喫

ダウンロードされた本は端末のローカル本棚に保存され、オフライン環境でも音声読み上げ、ハイライト、メモ機能などを存分に活用できます。書籍カードの “Where from” メニューから、続きの巻をダウンロードするために元のカタログへワンタップで戻ることも可能です。

💡 お役立ちメモ
自宅サーバーを運用する際は、localhost ではなくLAN内のIPアドレス（例：192.168.1.10）を指定し、末尾に /opds を含めることをお忘れなく。
7随时随地享受沉浸式离线阅读

下载的书籍会安放于本地书架，离线状态下同样支持语音朗读（TTS）、高亮划线与笔记功能。书籍卡片附带来源标记，点击菜单中的 “Where from” 还可快速回到原书库下载后续卷册。

💡 实用小贴士
在家庭局域网自建服务时，请务必使用电脑的局域网 IP（如 192.168.1.10）而非 localhost，并确保路径以 /opds 结尾。
7Aproveite Sua Leitura Off-line a Qualquer Hora

O livro baixado fica salvo na sua estante local, pronto para leitura off-line, conversão de texto em voz (TTS), destaques e anotações. O menu “Where from” no cartão do livro permite retornar direto ao catálogo quando quiser baixar o próximo volume.

💡 Dica Útil
Hospedando em casa? Use o IP da rede local (ex: 192.168.1.10) em vez de localhost e certifique-se de apontar para o caminho /opds.
7Disfruta de tu Lectura Sin Conexión

El libro descargado se almacena en tu estantería local, listo para lectura off-line, narración por voz (TTS), notas y subrayados. La opción “Where from” en la tarjeta del libro te permite volver al catálogo original para conseguir el siguiente tomo.

💡 Consejo Práctico
Si tienes tu propio servidor en casa, usa la IP local (ej. 192.168.1.10) en lugar de localhost y apunta siempre a la ruta /opds.

Preguntas Frecuentes (FAQ)

Does OPDS cost anything to use?
No. OPDS is an open, royalty-free standard, and Shiori's library-server features are completely free. Numerous excellent catalogs — including Project Gutenberg — are public and free to browse.
การใช้งาน OPDS มีค่าใช้จ่ายหรือไม่?
ไม่มีค่าใช้จ่ายใดๆ ครับ OPDS เป็นมาตรฐานเปิดสากล และฟังก์ชันเชื่อมต่อเซิร์ฟเวอร์ใน Shiori ให้บริการฟรีทั้งหมด นอกจากนี้ยังมีคลังหนังสือสาธารณะชั้นยอดอย่าง Project Gutenberg ให้เปิดอ่านได้ฟรีอีกด้วย
OPDSの利用に料金はかかりますか？
一切かかりません。OPDSはオープンな国際標準規格であり、Shioriのライブラリサーバー機能も完全無料でご利用いただけます。Project Gutenbergをはじめとする数多くの公開カタログも無料で利用可能です。
使用 OPDS 是否需要付费？
完全免费。OPDS 是一项开放的技术标准，Shiori 的书库服务器功能亦完全免费开放。互联网上还有众多优质的免费公开书库（如 Project Gutenberg）供您自由浏览。
O OPDS tem algum custo de uso?
Não. O OPDS é um padrão aberto e gratuito, e os recursos de servidor de biblioteca do Shiori são totalmente gratuitos. Muitos catálogos excelentes, como o Project Gutenberg, são públicos e livres.
¿OPDS tiene algún coste?
No. Es un estándar abierto y gratuito, y las funciones de servidor de biblioteca en Shiori son totalmente libres. Existen magníficos catálogos públicos como Project Gutenberg accesibles sin coste alguno.
Do I have to upload my books to any third-party cloud?
No. Shiori communicates directly with your own server over your local network or internet connection. None of your books or metadata pass through external sync servers.
ต้องอัปโหลดหนังสือไปยังคลาวด์ของบุคคลที่สามหรือไม่?
ไม่ต้องเลยครับ Shiori เชื่อมต่อกับเซิร์ฟเวอร์ของคุณโดยตรงแบบเครื่องต่อเครื่อง ข้อมูลและไฟล์หนังสือทั้งหมดจะอยู่ในการดูแลของคุณ 100% ไม่ผ่านเซิร์ฟเวอร์คนกลาง
本を外部のクラウドサービスにアップロードする必要がありますか？
いいえ、不要です。Shioriはお使いのスマートフォンから直接サーバーと通信するため、サードパーティの同期サーバーを経由することはありません。
我需要把图书上传到第三方云端吗？
不需要。Shiori 直接在手机与您的个人服务器之间建立点对点通信，没有任何文件或阅读数据会经由第三方服务器中转。
Preciso enviar meus livros para alguma nuvem de terceiros?
Não. O Shiori comunica-se diretamente com o seu servidor. Nada passa por serviços intermediários de sincronização.
¿Debo subir mis libros a algún servicio en la nube externo?
No. Shiori se comunica directamente con tu servidor. Ningún archivo ni metadato pasa por plataformas de terceros.
Which file formats can I download from an OPDS catalog?
You can download EPUB, PDF, FB2, and CBZ/CBR comic files — whichever supported formats your catalog provides for a given title.
สามารถดาวน์โหลดไฟล์หนังสือรูปแบบใดได้บ้าง?
รองรับทั้งไฟล์ EPUB, PDF, FB2 และไฟล์การ์ตูน CBZ/CBR ตามแต่ที่แคตตาล็อกต้นทางของคุณจัดเตรียมไว้ครับ
OPDSカタログからダウンロードできるファイル形式は？
EPUB、PDF、FB2、およびCBZ/CBR形式のコミックに対応しています（カタログ側で提供されているフォーマットに準じます）。
可以从 OPDS 目录中下载哪些格式的图书？
全面支持 EPUB、PDF、FB2 以及 CBZ/CBR 漫画格式——取决于您的书库源为该书提供了何种格式。
Quais formatos de arquivo posso baixar do catálogo OPDS?
Você pode baixar arquivos EPUB, PDF, FB2 e quadrinhos CBZ/CBR — conforme disponibilizado pelo seu catálogo.
¿Qué formatos de archivo puedo descargar desde un catálogo OPDS?
Puedes descargar libros en EPUB, PDF, FB2 y cómics en CBZ/CBR, según los formatos que ofrezca tu catálogo para cada título.
Can I add more than one catalog at the same time?
Yes! You can add as many catalogs as you like. They all appear neatly in your Library Server list, and you can reorder them to keep your favorite servers right at the top.
สามารถเพิ่มหลายๆ เซิร์ฟเวอร์พร้อมกันได้หรือไม่?
