You just downloaded a course archive, a story bundle, or a folder of books someone shared with you, and it landed on your phone as one .zip file with half a dozen books inside it. The usual routine is to find a file manager, extract the archive, and import the books one by one — an unnecessary chore every single time.

Shiori skips that step completely. Point the file picker at the ZIP file itself, and Shiori unpacks it and adds every book inside straight to your bookshelf.

Shiori's file picker treats a .zip archive the same way it treats any book file — it is never greyed out or hidden from the list. Select it, and Shiori looks inside, pulls out each supported book, and adds it to your library as its own independent entry: its own cover, title, author metadata, and reading progress.

What Happens When You Import a ZIP

  • Independent bookshelf entries: Nothing stays bundled inside an archive container. Each file becomes a standalone book with its own position tracking.

1Pick the ZIP in the File Picker

On your bookshelf, tap the floating + button in the bottom-right corner. The system file picker opens to browse your device.

A ZIP archive appears in the list looking just like any other book file — same row style, same thumbnail — because Shiori can read what is packed inside. Tap the archive file just as you would tap a single book.

1เลือกไฟล์ ZIP ในหน้าต่างเลือกไฟล์

บนหน้าชั้นหนังสือ ให้แตะปุ่ม + ที่มุมล่างขวาเพื่อเปิดหน้าต่างเลือกไฟล์ของระบบ

ไฟล์ ZIP จะแสดงอยู่ในรายการเหมือนไฟล์หนังสือทั่วไป สามารถกดเลือกได้ทันทีโดยไม่ต้องแตกไฟล์ล่วงหน้า

1ファイル選択画面でZIPファイルを選ぶ

本棚画面の右下にある + ボタンをタップしてファイル選択画面を開きます。

ZIPアーカイブは通常の書籍ファイルと同じように選択可能に表示されます。そのままタップして選択してください。

1在文件选择器中选中 ZIP 压缩包

在书架界面点击右下角的 + 悬浮按钮，打开系统文件选择器。

ZIP 压缩包将同普通图书文件一样正常展示在列表中，无需预先解压，直接点击即可开始导入。

1Selecione o Arquivo ZIP no Seletor

Na estante, toque no botão + no canto inferior direito para abrir o seletor.

O arquivo ZIP aparece como qualquer outro livro. Basta tocar nele para iniciar a descompactação automática.

1Elige el Archivo ZIP en el Selector

En la estantería, toca el botón + en la esquina inferior derecha para abrir el selector.

El archivo ZIP aparece habilitado en la lista. Tócalo igual que si fuera un libro individual.

2Each Book Lands on the Shelf Individually

Shiori unpacks the archive, discovers every supported book, and imports each one separately onto your bookshelf.

In this example, one ZIP held two completely different books — a philosophy text and an illustrated Japanese scroll. Both appear with their real titles, authors, and cover art pulled from their metadata.

在此示例中，一个 ZIP 包内包含两本截然不同的图书（古典哲学书与日本绘卷），两者均正确显示其真实的书名、作者以及高清封面。

O Shiori extrai o arquivo e adiciona cada e-book separadamente na sua biblioteca.

Preguntas Frecuentes y Solución de Problemas (FAQ)

Why doesn't a book from the ZIP show up as newly added?
Shiori checks each extracted book against your current library to prevent duplicates. If a title is missing from the recently imported section, it is already on your shelf under its existing entry.
ทำไมหนังสือบางเล่มใน ZIP ถึงไม่ขึ้นเป็นหนังสือที่เพิ่งนำเข้าใหม่?
Shiori มีระบบตรวจสอบหนังสือซ้ำอัตโนมัติ หากหนังสือเล่มนั้นมีอยู่แล้วในคลังของคุณ ระบบจะไม่สร้างรายการซ้ำ คุณสามารถเปิดอ่านต่อจากรายการเดิมที่มีอยู่แล้วได้ทันที
ZIP内の本が「新規追加」として表示されないのはなぜですか？
Shioriは重複防止機能を備えています。すでに本棚にある本は再登録されないため、以前からライブラリ内に存在しているかご確認ください。
为什么 ZIP 里的某本书没有显示在最新导入列表中？
Shiori 具备智能查重机制。如果该图书已存在于书架中，系统会自动跳过以防止产生重复条目。
Por que um livro do ZIP não aparece como recém-adicionado?
O Shiori verifica duplicatas automaticamente. Se o título já estiver na sua estante, ele não será duplicado.
¿Por qué un libro del ZIP no aparece como recién añadido?
Shiori comprueba si ya tienes el libro en tu biblioteca para no crear duplicados. Si ya existía, se mantendrá su entrada original.
Can I zip an entire folder on my PC to transfer it quickly?
Yes! Compressing a folder of books into a single .zip file on your computer is the fastest way to transfer dozens of books at once. On your phone, one tap on the ZIP imports the whole collection.
